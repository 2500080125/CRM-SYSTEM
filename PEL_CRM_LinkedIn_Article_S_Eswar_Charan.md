

CRM SYSTEMS FRONTEND PROJECT

Building PEL CRM: Upgraded with React + Vite

I’m excited to share the upgraded version of my CRM project, PEL CRM, developed as part of my BTech AI \& Data Science coursework at KL University.



This project began as a frontend CRM prototype and has now been upgraded using React and Vite to create a faster, component-based, and more structured web application.



What the project does

PEL CRM helps users manage:



Customers



Sales pipeline opportunities



Tasks and follow-ups



Personal profile and dashboard preferences



The project has two separate modules:



User Portal — each user can create and manage only their own customers, opportunities, and tasks.



Admin Portal — the administrator can view all registered users, monitor user-wise CRM records, assign records, and manage the overall workspace.



Technologies used

React — used to build reusable UI components and update the interface dynamically without page reloads.



Vite — used for fast development and optimized production builds.



HTML and CSS — used for the page structure, responsive layout, styling, dashboard cards, forms, modals, and Monsoon-inspired visual design.



JavaScript — used for CRM logic, validation, CRUD operations, task completion, filters, role-based views, and notifications.



Local Storage — stores user accounts, customers, pipeline records, tasks, settings, and activity in the browser.



Session Storage — stores the active login session and identifies whether the current session is a User or Admin.



GitHub — used for version control.



Vercel — used to deploy the React + Vite application online.



Key features implemented

User Sign Up and Sign In



Separate Admin login page using /admin



Role-based User and Admin dashboards



Add, edit, and delete customers, pipeline opportunities, and tasks



Task priority, due date, notes, and completion tracking



User-wise record ownership and Admin assignment



Dashboard metrics for customers, pipeline value, and pending tasks



Dark/light mode toggle



Language and layout preferences



Login loading indicator and validation messages



Delete confirmation pop-ups



Browser-based data persistence after page refresh



Important learning

This project helped me understand how React state, reusable components, browser storage, role-based rendering, and deployment work together in a real application.



Since this is a frontend-only academic project, the data is stored in the browser and is not production-level secure. In a future version, I plan to add a backend, database, secure authentication, and cloud-based multi-device access.
